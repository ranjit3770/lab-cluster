# 🔐 PRE-PRODUCTION SECURITY CHECKLIST

**Compute Resource & Job Execution Platform**

---

## 1️⃣ AUTHENTICATION & AUTHORIZATION (CRITICAL)

### Backend (MUST PASS)

* [ ] **JWT access tokens**

  * Short-lived (≤ 30 minutes)
* [ ] **Refresh tokens**

  * HttpOnly cookie only
  * Rotated on every refresh
* [ ] **Password hashing**

  * bcrypt / argon2
  * No plaintext passwords anywhere
* [ ] **RBAC enforced server-side**

  * SUPER_ADMIN vs USER
  * No frontend-only checks
* [ ] **403 on privilege escalation**

  * User → admin endpoints blocked
* [ ] **Admin routes require role check**

  * Not just authentication

### Frontend (Defense-in-depth)

* [ ] Route guards active
* [ ] Admin components never imported into user layout
* [ ] Sidebar/menu filtered by role
* [ ] Forced redirect to `/403` on 403 response

✅ **Pass condition:**
User with valid JWT **cannot access admin APIs even via curl**

---

## 2️⃣ API SECURITY

* [ ] **CORS restricted**

  * Exact frontend domain(s)
  * No `*` in prod
* [ ] **Rate limiting**

  * Login endpoint
  * Job submission endpoint
* [ ] **Request body validation**

  * Pydantic schemas everywhere
* [ ] **Reject unknown fields**
* [ ] **Strict HTTP methods**

  * No GET → mutate
* [ ] **Pagination enforced**

  * No unlimited list endpoints

✅ **Pass condition:**
Malformed or oversized requests are rejected early

---

## 3️⃣ JOB EXECUTION & CLUSTER SAFETY (VERY IMPORTANT)

* [ ] **User input never executed directly**

  * Commands passed via controlled executor
* [ ] **No shell=True**
* [ ] **Argument escaping enforced**
* [ ] **Execution runs under restricted OS user**
* [ ] **No filesystem access outside sandbox**
* [ ] **No network access unless required**
* [ ] **Ray job metadata sanitized**
* [ ] **One running job per user enforced backend-side**

🚨 **RED FLAG:**
If a user can run `rm -rf /` or access `/etc` → DO NOT DEPLOY

---

## 4️⃣ RESOURCE GOVERNANCE & QUOTAS

* [ ] CPU & RAM limits enforced server-side
* [ ] Node-wise quota strictly respected
* [ ] No user-defined resource overrides
* [ ] Free resources recalculated on every job
* [ ] Failed jobs release resources
* [ ] Node DOWN triggers resource cleanup
* [ ] Idle resource revocation tested

✅ **Pass condition:**
Resource counters never go negative or drift

---

## 5️⃣ NODE & HEARTBEAT SECURITY

* [ ] Heartbeat endpoint authenticated (token or mTLS)
* [ ] Heartbeat timeout enforced
* [ ] Node cannot spoof another node ID
* [ ] Node registration is admin-only
* [ ] DOWN nodes blocked from scheduling
* [ ] DEGRADED nodes handled gracefully

🚨 **RED FLAG:**
If a node can fake heartbeat and gain resources → fix immediately

---

## 6️⃣ AUDIT LOG INTEGRITY (NON-NEGOTIABLE)

* [ ] Every sensitive action logged:

  * Login
  * Job submit
  * Job retry
  * Quota change
  * Node down/up
* [ ] Logs are append-only
* [ ] No UPDATE / DELETE on audit logs
* [ ] Timestamps are UTC
* [ ] Actor, action, target always present
* [ ] Audit logs admin-read-only

✅ **Pass condition:**
You can reconstruct *who did what and when*

---

## 7️⃣ DATABASE SECURITY

* [ ] Dedicated DB user per service
* [ ] No root credentials in app
* [ ] Least-privilege grants
* [ ] Prepared statements only
* [ ] No raw string SQL
* [ ] Foreign keys enforced
* [ ] Cascades reviewed carefully
* [ ] Alembic migrations locked

---

## 8️⃣ FRONTEND SECURITY

* [ ] No secrets in frontend build
* [ ] JWT never stored in localStorage (prod)
* [ ] HttpOnly cookies preferred
* [ ] CSP headers enabled
* [ ] XSS prevention (no dangerouslySetInnerHTML)
* [ ] User input escaped
* [ ] Axios 401/403 handled correctly
* [ ] Error boundary active

---

## 9️⃣ DEPLOYMENT & INFRA

* [ ] HTTPS everywhere (TLS 1.2+)
* [ ] Secure headers:

  * X-Frame-Options
  * X-Content-Type-Options
  * Referrer-Policy
* [ ] Environment variables only
* [ ] `.env` not in repo
* [ ] Debug disabled
* [ ] Uvicorn/Gunicorn hardened
* [ ] Reverse proxy (Nginx) rate limiting enabled

* ❌ Users can override CPU/RAM

* ❌ Audit logs editable
